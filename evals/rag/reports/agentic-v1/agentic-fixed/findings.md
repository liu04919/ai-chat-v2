# 人工复核与结论边界

本记录解释同目录 `comparison.json` 的分数，不改写模型回答、原始参考答案或评分。回答由本地 Proxy 的 Sol 生成；Astra 经 Ragas 评分。人工复核只解释案例，不冒充第二轮独立盲评。

## 本轮结论

| 指标 | 传统 | Agentic 修复版 |
| --- | ---: | ---: |
| AnswerAccuracy 均值 | 0.885 | 0.860 |
| Faithfulness 均值 | 0.9816 | 0.8900 |
| 已知答案区间命中 | 50/50 | 50/50 |
| 回答完成耗时中位数 | 5.08 秒 | 9.93 秒 |
| 回答完成耗时 P95 | 11.28 秒 | 36.83 秒 |
| 生成模型请求数（含失败尝试） | 50 | 111 |

正确性分数提高 / 持平 / 下降为 3 / 42 / 5。配对差值的 bootstrap 95% 区间：AnswerAccuracy 为 [-0.070, 0.015]，跨过零；Faithfulness 为 [-0.1421, -0.0471]。本样本没有证明 Agentic 正确性提升，忠实度评分反而下降。不能据此断言所有场景下传统 RAG 都更好。

两版均已命中已知答案区间，这批短事实问题给追加检索留下的收益空间有限。Agentic 最终平均调用知识库 1.22 次，资料平均 6.48 条；传统固定预检索一次，不属于模型工具调用，因此原始表中其 `knowledgeCallsMean` 为 0，并非没有检索。

付费 Embedding 与 rerank 的共享账本累计估算 ¥1.990665 / ¥10，无未结算请求；包含之前失败版、试跑、主对照和专项。Sol / Astra 使用订阅额度，不折算人民币。Agentic 有两次请求缺少 usage，token 统计只代表已知部分。独立评测服务已停止，数据保留，本地 Proxy 不作改动。

## 修复效果与连接失败分开看

- 原版 Agentic 首次完成 43/50，七次累计来源超过 SSE 的六条上限而失败；原始结果保留在上级报告中。
- 来源契约统一为 18 条后，独立重跑全部 50 题，首次完成 48/50。
- 两次失败的 Worker 日志包含 `upstream_transport_error`、`tls handshake eof`，发生在 Proxy 上游连接阶段，不是来源契约错误。确认原因后仅补跑这两题，最终 50 题完成，共 52 次生成尝试。
- 六题发生多次知识库调用，五题累计来源超过六条，最多自然产生 13 条。此处证明真实调用链能处理多次检索；18 条边界由契约、前端投影及真实 Redis 事件回放测试覆盖，并非声称线上样本恰好输出了 18 条。

## 有答案，不代表所有解释都被资料支持

`DEV_594_QUERY_2` 问《张居正》描写的人物。传统回答以资料列举的姓名为主；Agentic 增添人物身份、政治关系等解释。Ragas 对 Agentic 给出 Faithfulness 约 0.486，AnswerAccuracy 0.75。核查重点是这些额外断言有没有检索证据，而非回答是否更长、更像百科。

`DEV_341_QUERY_2` 问瑞尼尔山为何可能引发巨大火山泥流。命中的原文明确说“由于庞大的冰川”，Agentic 进一步解释迅速融化、与灰岩碎屑混合、沿河谷高速下泄。评分为 Faithfulness 0.2，AnswerAccuracy 0.75：核心原因回答到了，但额外机制在该条资料中没有展开。缺少来源支持不等于这些机制在现实世界中必然错误，也不能反过来把常识正确当作有出处。

这类问题可作为下一轮改进假设：让模型在资料足够时停止检索，回答紧扣证据，避免给事实查询增加无来源的背景。当前评测期间没有据此修改业务提示词或重跑低分题。

## 数据集与裁判也有边界

`DEV_412_QUERY_2` 问诺丁汉郡第一大镇。上游的三个人工答案是“诺定咸”“诺定咸”“曼斯菲尔德”，本身不一致。检索原文区分第一大城市与第一大镇，两版都回答曼斯菲尔德；沿用冻结的“第一个人工答案”策略后，两版 AnswerAccuracy 均为 0，而 Faithfulness 均为 1。

没有临时挑选有利参考答案来提高分数。报告保留全部参考答案供复核；因此这些均值不能直接称为绝对正确率。裁判的断言拆分与评分也有随机性，50 题一次生成的配对差异只能说明本轮表现。

提高分数的三个案例也不能全部当成能力提升。例如 `DEV_606_QUERY_2` 两版都写了岩礁底质、圆石斜坡和 1–35 米水深，却分别得到 0.5 和 0.75；`DEV_601_QUERY_3` 两版核心答案也都是多数人的共识，分数为 0.75 和 1。相比之下，`DEV_254_QUERY_1` 中 Agentic 对行政面积与建成区的区分更清楚，是值得继续检查的正例。报告保留这些原始分数，但不把裁判的所有细小差异解释成模型真实进步。

## 专项能力和总体质量是两回事

手工专项验证了不必检索时直接回答、根据检索结果追加 query、多轮指代解析、资料不足时拒答，以及一个简单的文档指令隔离样本。详见 `special-cases.md`。这些功能成立，不自动意味着在公开事实问答回归上比固定预检索更准确。

CMRC 主对照生成及两次补跑均在专项文档导入前完成。专项导入后只对冻结回答评分，没有在改变后的共享 BM25 语料统计上偷偷重生成主对照答案。
